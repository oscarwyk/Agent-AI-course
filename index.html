01

課程簡介

生成式 AI 正從「回答問題」走向「完成任務」。Agent AI 結合大型語言模型的推理能力與外部工具、記憶與規劃機制， 是目前學界與產業最受關注的方向之一。修完本課程後，你將能夠：

1

理解核心原理

掌握 LLM、提示工程、ReAct、Chain-of-Thought 等 Agent 背後的關鍵概念。

2

動手打造 Agent

學會讓模型呼叫工具（Tool Use / Function Calling）、串接 API 與管理記憶。

3

設計多代理系統

探討 Multi-Agent 協作、評估方法與安全性，並完成期末專題。

    03

    課程進度

    以下為暫定規劃，實際進度以課堂公告為準。

    W1–W3

    LLM 基礎與提示工程

    Transformer 概念、Prompting 技巧、Chain-of-Thought。

    W4–W6

    Agent 架構

    ReAct、規劃（Planning）、反思（Reflection）與記憶機制。

    W7–W9

    工具使用與實作

    Function Calling、RAG、串接外部 API，實作第一個 Agent。

    W10–W13

    多代理系統與評估

    Multi-Agent 協作、Benchmark、安全性與對齊議題。

    W14–W18

    期末專題

    分組設計並展示自己的 Agent 應用。
