Agentic AI：
用 Claude 打造你的 AI 教學助手

AI 不再只是回答問題，而是能幫你「完成任務」。本課程以 Claude 為工具， 從安裝設定開始，一步步建立專屬的教學生成 Agent，最後產出一套可以直接拿來上課的教學大綱、投影片與講義。

對象電機系教師（工作坊）· 下學期修課學生
形式4 支教學影片 ＋ 12 週課程
工具Claude

01

課程簡介

整個課程圍繞一個實際任務：讓 AI Agent 幫你準備一門課。四支影片對應四個步驟，看完並跟著操作，你就會有一套自己的教材。

1

準備環境

認識什麼是 Agentic AI，下載 Claude、註冊帳號，熟悉介面與側欄功能。

成果：完成帳號與環境設定
2

建立 Agent

建立專案，設定 Instructions、Folder 與 Skill，讓 Claude 成為懂你課程的助手。

成果：一個可用的教學生成 Agent
3

產生教材

用 Agent 產出教學大綱、投影片（PPT）與講義，體驗從指令到檔案的完整流程。

成果：教學大綱、投影片、講義
4

細化與進階

把教學大綱逐步細化成每週內容，搭配協作功能與進階技巧，走完一個完整案例。

成果：一套可直接授課的教材
02

申請帳號

請依身分選擇方案申請 Claude 帳號，申請步驟請看 投影片或 EP0 影片。

      04

      打造 Agent 的三個設定

      一般聊天每次都要重新交代背景；建立專案並做好這三項設定後，Claude 就會記得你是誰、要做什麼、該怎麼做。（對應第 2 支影片）

      INSTRUCTIONS

      指令：告訴它「你是誰」

      為 Agent 設定角色、目標與規則，例如語氣、格式、使用的語言。

      例：「你是電機系的教學助理，所有教材以繁體中文撰寫，每週內容包含學習目標、重點與練習題。」
      FOLDER

      資料夾：給它「參考資料」

      把課本章節、舊講義、課程規定等檔案放進去，Agent 會依據這些資料產出內容。

      例：放入去年的課程大綱與上課講義 PDF，讓新教材延續原本的風格。
      SKILL

      技能：教它「怎麼做」

      把重複使用的流程包裝成 Skill，例如「照系上格式做投影片」，之後一句話就能套用。

      例：建立「每週講義」Skill，固定產出封面、學習目標、內容與課後練習。
